# محلل نقاط المساحة — Survey Points Analyzer (GeoTech)

> **EN:** A browser-based tool to load, clean, filter, analyze and export GPS survey points (GeoJSON / Shapefile). Everything runs locally in your browser — no data is uploaded anywhere.

أداة ويب تشتغل بالكامل داخل المتصفح لتحميل نقاط الرفع المساحي (GPS) وعرضها على الخريطة، وتنظيفها من التكرار، وفلترتها، وتحليل توزيعها المكاني، ثم تصديرها. **البيانات بتفضل على جهازك ومبتترفعش لأي سيرفر.**

---

## الإمكانيات

### تحميل البيانات
- ملفات **GeoJSON** (`.geojson` / `.json`).
- **Shapefile** على شكل ملف ZIP، أو ملفات `.shp` + `.dbf` + `.prj` مع بعض.
- لصق نص GeoJSON مباشرة.
- تحميل أكتر من ملف بيدمج النقاط مع بعض.

### الحقول المدعومة
الأداة بتوحّد أسماء الحقول (مش حساسة لحالة الحروف):

| الحقل | المعنى |
|---|---|
| `Code_Num` | رقم/كود الطلب |
| `JobName` | اسم المشروع |
| `PointNum` | رقم النقطة |
| `IsBase` | هل هي نقطة قاعدة (Base) |
| `CoordSys` / `Datum` | نظام الإحداثيات / المرجع |
| `Lat` / `Lon` | خط العرض / خط الطول |
| `Elev` | المنسوب |
| `Northing` / `Easting` | الإحداثيات المستوية |

### التنظيف والفلاتر
- **حذف التكرار بالبافر:** بتحدد مسافة (بالسم أو المتر)، وأي نقطتين بنفس `Code_Num` أقرب من المسافة دي بيتعتبروا تكرار، وبيتحتفظ بالنقطة الأكمل بيانات. فيه **معاينة بالأحمر** على الخريطة قبل الحذف، مع إمكانية الإلغاء أو الرجوع للأصل.
- إظهار نقاط القاعدة (Base) فقط.
- فلتر نطاق المنسوب (أدنى / أعلى).
- فلتر حسب `Code_Num`.
- **رسم منطقة (Polygon)** على الخريطة لتحديد النقاط جواها.

### أدوات القياس على الخريطة
- قياس المسافة بين نقطتين.
- إيجاد أقرب نقطة لنقطة معينة.

### الإحصائيات المكانية
- **رسم بياني بعدد النقاط في كل محافظة** (بيتحدّث مع الفلاتر، والضغط على العمود بينقلك للمحافظة).
- Standard Distance، ومتوسط أقرب جار (NN)، ومؤشر NNI.
- مساحة Convex Hull والكثافة.
- كشف النقاط الشاذة (متوسط المسافة عن المركز + 2 انحراف معياري).

### الخريطة والطبقات
- **صورة القمر الصناعي** (Esri World Imagery) هي الخلفية الافتراضية، مع خلفيات فاتحة وداكنة (CARTO).
- لوحة طبقات: إظهار/إخفاء، ترتيب، وشفافية لطبقة النقاط وطبقة محافظات مصر.
- جدول عدد النقاط داخل كل محافظة.
- تلوين النقاط حسب الكود أو حسب نقاط القاعدة.
- النقاط بتترسم بـ **deck.gl** (على كارت الشاشة) فبتتحمل آلاف النقاط بسلاسة.

### التصدير
- **GeoJSON**
- **CSV** (بترميز يفتح العربي سليم في Excel)
- **Shapefile** (ملف ZIP فيه `.shp .shx .dbf .prj .cpg` بنظام WGS84 وترميز UTF-8)

> التصدير بيشمل **النقاط الظاهرة بعد الفلاتر** فقط.

| الغرض | المكتبة |
|---|---|
| الواجهة | React + TypeScript + Vite |
| الخريطة | [MapLibre GL JS](https://maplibre.org/) |

| الرسوم البيانية | [Chart.js](https://www.chartjs.org/) |
| الأيقونات | [lucide-react](https://lucide.dev/) |

## التشغيل على جهازك

**المتطلبات:** [Node.js](https://nodejs.org/) إصدار 18 أو أحدث.

```bash
# 1) نزّل المشروع
git clone https://github.com/<اسم-المستخدم>/<اسم-الريبو>.git
cd <اسم-الريبو>

# 2) نزّل المكتبات
npm install

# 3) شغّل المشروع
npm run dev
```

بعدها افتح الرابط اللي هيظهر في الـ terminal (غالباً `http://localhost:5173`).

### بناء نسخة للنشر

```bash
npm run build      # بيطلّع مجلد dist
npm run preview    # لتجربة النسخة المبنية محلياً
```

> محتاج اتصال إنترنت وقت التشغيل لتحميل خلفيات الخرائط (CARTO وEsri).
